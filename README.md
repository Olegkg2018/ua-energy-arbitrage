# UA Energy Arbitrage & Price Forecasting AI 🇺🇦 (BESS EMS)

Програмно-апаратний симулятор та система управління (EMS) для прогнозування цін на ринку «на добу наперед» (РДН) в Україні та автоматичної оптимізації графіків роботи промислових систем накопичення енергії (BESS / АКБ).

Комплекс дозволяє максимізувати прибуток від енергоарбітражу або мінімізувати витрати підприємства при заміщенні власного споживання (Behind-the-Meter).

---

## 🌟 Основні можливості

1. **Прогнозування цін РДН (AI Forecasting)**:
   * Використання двох моделей машинного навчання: **XGBoost Regressor** та **MLP (нейронна мережа)**.
   * Навчання на безперервному історичному масиві цін РДН України з 1 січня 2021 року по червень 2026 року (понад 48 000 годин).
   * Автоматичне врахування температурного дрейфу, сонячної радіації (активності сонця), хмарності та календарних ефектів (будні, вихідні, державні свята України).
2. **Сценарії та стрес-тести (Scenario Modeling)**:
   * Фізичне моделювання енергосистеми за допомогою повзунків: ціна на газ, аварійний імпорт з ЄС, дефіцит блоків АЕС, коефіцієнт попиту та пошкодження сонячних електростанцій (СЕС).
3. **Математична оптимізація (PuLP Solver)**:
   * Лінійне програмування для побудови ідеального графіка роботи батареї з урахуванням ККД заряду/розряду, лімітів глибини розряду (SoC $10\% - 90\%$) та вартості деградації осередків.
4. **Інтерактивне ручне керування (Manual Override)**:
   * Диспетчер може вручну перетягувати стовпчики на графіку: **вертикально** (для точного налаштування потужності) та **горизонтально** (для перенесення години заряду/розряду).
   * Можливість ручного вибору режимів безпосередньо в таблиці погодинної відомості.
5. **Система автобалансування (BMS Auto-Balance)**:
   * Кнопка автоматичного розрахунку добового енергетичного балансу батареї для повернення до початкової ємності на кінець доби («вихід в нуль») та дотримання безпечних меж SoC.
6. **Інтеграція з тарифами ОСР України**:
   * Вбудований довідник тарифів 1 та 2 класів напруги для всіх обленерго України (ДТЕК, Укренерго тощо) для розрахунку чистої окупності.
7. **Синхронізація у реальному часі**:
   * Парсинг поточних цін РДН безпосередньо з офіційного порталу ДП «Оператор ринку» (`oree.com.ua`).

## 📂 Структура розділів додатка (Вкладки)

*   **Панель інструментів (Головний дашборд)**:
    *   Основні KPI-показники: чистий прибуток за добу, витрати на зарядку, дохід від розряду, кількість циклів.
    *   Графік прогнозу цін (у порівнянні з фактичними цінами РДН).
    *   Інтерактивний графік BESS (потужність заряду/розряду суміщена з лінією рівня SoC).
*   **Погодинний графік (Почасова відомість)**:
    *   Таблиця з детальними фінансовими та технічними параметрами кожної години.
    *   Інтерактивні поля зміни потужності та вибору режиму АКБ.
    *   Кнопки експорту графіка в CSV для EMS та примусового автобалансу BMS.
*   **Сценарний аналіз**:
    *   Панель запуску сценаріїв («Світова газова криза», «Обстріли сонячної генерації», «Максимальний імпорт з ЄС»).
    *   Картки оцінки ризиків окупності проєкту BESS.
*   **Довідник тарифів та АКБ**:
    *   Тарифна сітка обленерго України.
    *   Довідник характеристик акумуляторів (LFP осередки, NMC осередки).
*   **Журнал імпортів та помилок**:
    *   Вбудована консоль EMS, що логує мережеві запити, відповіді солвера та дії користувача в реальному часі.
    *   Панель експрес-верифікації бази даних РДН.

## 🚀 Інсталяція та запуск

### Варіант 1: Локальний запуск (Python)

#### 1. Підготовка оточення та встановлення залежностей
Рекомендується використовувати Python 3.10 або новішої версії.

```bash
# Клонуйте репозиторій
git clone https://github.com/Olegkg2018/ua-energy-arbitrage.git
cd ua-energy-arbitrage

# Створіть та активуйте віртуальне оточення
python3 -m venv venv
source venv/bin/activate

# Встановіть бібліотеки
pip install -r requirements.txt
```

#### 2. Запуск веб-інтерфейсу
```bash
python3 app.py
```
Додаток запуститься в режимі реального часу і буде доступний у браузері за адресою: [http://127.0.0.1:5000](http://127.0.0.1:5000).

---

### Варіант 2: Запуск в Docker

Ви можете запустити додаток в ізольованому контейнері без встановлення Python на локальну машину.

#### 1. Збірка Docker-образу
```bash
docker build -t ua-energy-arbitrage .
```

#### 2. Запуск контейнера
```bash
docker run -d -p 5002:5000 --name ua-energy-arbitrage ua-energy-arbitrage
```
Після запуску проєкт буде доступний за адресою: [http://127.0.0.1:5002](http://127.0.0.1:5002).

---

### Варіант 3: Запуск через Docker Compose (Рекомендований)

Для швидкого керування контейнерами використовуйте Docker Compose.

*   **Запустити у фоновому режимі**:
    ```bash
    docker compose up -d
    ```
*   **Зупинити та видалити контейнер**:
    ```bash
    docker compose down
    ```

## 💡 Як працювати з програмою (Інструкція диспетчера)

### Крок 1. Задання параметрів обладнання та тарифів
1. У лівій частині екрана введіть технічні характеристики вашої BESS: **Ємність (кВт-год)** (наприклад, 4000) та **Потужність (кВт)** (наприклад, 1000).
2. Встановіть **Вхідну ємність (Початковий SoC, %)** (наприклад, 20% або 100%, якщо батарея заряджена з попередньої доби).
3. Перейдіть у вкладку «Довідник тарифів та АКБ» та в один клік застосуйте мережевий тариф потрібного вам Обленерго України. Тариф автоматично розрахує вартість передачі, розподілу та диспетчеризації.

### Крок 2. Розрахунок автоматичного оптимуму
1. Виберіть дату планування на верхній панелі та модель штучного інтелекту (рекомендується **XGBoost**).
2. Натисніть кнопку **«Розрахувати Розклад»**.
3. Система за секунду виконає прогноз цін РДН, перевірить погоду та побудує математично оптимальний графік BESS за допомогою солвера PuLP (CBC).
4. Ознайомтеся з фінансовим результатом у картці «Чистий прибуток». Він враховує амортизацію батареї (деградацію осередків).

### Крок 3. Ручне коригування графіка
Якщо ви хочете перевизначити години роботи батареї вручну:
*   **Перетягування стовпчиків по висоті**: Наведіть мишу на бірюзовий (заряд) або рожевий (розряд) стовпчик на графіку потужності BESS та перетягніть його край вгору або вниз для зміни кіловат.
*   **Переміщення стовпчика по годинах**: Захопіть стовпчик мишкою та потягніть його горизонтально вліво або вправо. Відпустіть мишу над потрібною годиною. Блок потужності переміститься на новий час без зміни висоти.
*   **Редагування через таблицю**: Перейдіть у вкладку **«Погодинний графік»**. Виберіть режим години зі спадного списку та введіть точне значення потужності у кВт.
*   *Зверніть увагу*: Картка прибутку підсвітиться помаранчевим кольором і з'явиться індикатор **«Ручне керування»**.

### Крок 4. Автоматичне балансування BMS
При ручному редагуванні легко припуститися перерозряду батареї нижче мінімуму або залишити її в кінці доби розрядженою, що принесе збитки на наступну добу.
*   Натисніть зелену кнопку **«Авто-баланс BMS»** у почасовій таблиці.
*   Система автоматично згладить ваші піки, щоб рівень заряду ніколи не опускався нижче $10\%$ і не перевищував $90\%$, а також скоригує заряд або розряд так, щоб наприкінці доби рівень енергії повернувся точно до значення **Вхідної ємності** (наприклад, 20%).
*   При необхідності скидання всіх ручних правок натисніть кнопку **«Скинути до оптимуму»**.

### Крок 5. Експорт результатів
Після узгодження графіка натисніть кнопку **«Експорт в CSV»** для вивантаження погодинного розкладу та імпорту його в промислову систему автоматизації (EMS) накопичувача.
