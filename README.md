# UA Energy Arbitrage & Price Forecasting AI 🇺🇦 (BESS EMS)

Программно-аппаратный симулятор и система управления (EMS) для прогнозирования цен на рынке «на сутки вперед» (РДН) в Украине и автоматической оптимизации графиков работы промышленных систем накопичения энергии (BESS / АКБ). 

Комплекс позволяет максимизировать прибыль от энергоарбитража или минимизировать затраты предприятия при замещении собственного потребления (Behind-the-Meter).

---

## 🌟 Основные возможности

1. **Прогнозирование цен РДН (AI Forecasting)**:
   * Использование двух моделей машинного обучения: **XGBoost Regressor** и **MLP (нейронная сеть)**.
   * Обучение на непрерывной истории цен РДН Украины с 1 января 2021 года по июнь 2026 года (более 48 000 часов).
   * Автоматический учет температурного дрейфа, солнечной радиации (солнечной активности), облачности и календарных эффектов (будни, выходные, государственные праздники Украины).
2. **Сценарии и стресс-тесты (Scenario Modeling)**:
   * Физическое моделирование энергосистемы с помощью ползунков: цена на газ, аварийный импорт из ЕС, дефицит блоков АЭС, коэффициент спроса и повреждения солнечных электростанций (СЕС).
3. **Математическая оптимизация (PuLP Solver)**:
   * Линейное программирование для построения идеального графика работы батареи с учетом КПД заряда/разряда, лимитов глубины разряда (SoC $10\% - 90\%$) и стоимости деградации ячеек.
4. **Интерактивное ручное управление (Manual Override)**:
   * Диспетчер может вручную перетаскивать столбики на графике: **вертикально** (для точной настройки мощности) и **горизонтально** (для переноса часа заряда/разряда).
   * Возможность ручного выбора режимов прямо в таблице почасовой ведомости.
5. **Система автобалансировки (BMS Auto-Balance)**:
   * Кнопка автоматического расчета суточного энергетического баланса батареи для возврата к исходной емкости на конец суток («выход в ноль») и соблюдения безопасных границ SoC.
6. **Интеграция с тарифами ОСР Украины**:
   * Встроенный справочник тарифов 1 и 2 классов напряжения для всех облэнерго Украины (ДТЭК, Укрэнерго и др.) для расчета чистой окупаемости.
7. **Синхронизация в реальном времени**:
   * Парсинг текущих цен РДН напрямую с официального портала ДП «Оператор рынка» (`oree.com.ua`).

## 📂 Структура разделов приложения (Вкладки)

*   **Панель інструментів (Главный дашборд)**:
    *   Основные KPI-показатели: чистая прибыль за сутки, затраты на зарядку, доход от разряда, количество циклов.
    *   График прогноза цен (в сравнении с фактическими ценами РДН).
    *   Интерактивный график BESS (мощность заряда/разряда совмещена с линией уровня SoC).
*   **Погодинний графік (Почасовая ведомость)**:
    *   Таблица с детальными финансовыми и техническими параметрами каждого часа.
    *   Интерактивные поля изменения мощности и выбора режима АКБ.
    *   Кнопки экспорта графика в CSV для EMS и принудительного автобаланса BMS.
*   **Сценарний аналіз**:
    *   Панель запуска сценариев («Мировой газовый кризис», «Обстрелы солнечной генерации», «Максимальный импорт из ЕС»).
    *   Карточки оценки рисков окупаемости проекта BESS.
*   **Довідник тарифів та АКБ**:
    *   Тарифная сетка облэнерго Украины.
    *   Справочник характеристик аккумуляторов (LFP ячейки, NMC ячейки).
*   **Журнал імпортів та помилок**:
    *   Встроенная консоль EMS, логирующая сетевые запросы, ответы солвера и действия пользователя в реальном времени.
    *   Панель экспресс-верификации базы данных РДН.

## 🚀 Инсталляция и запуск

### Вариант 1: Локальный запуск (Python)

#### 1. Подготовка окружения и установка зависимостей
Рекомендуется использовать Python 3.10 или более поздней версии.

```bash
# Клонируйте репозиторий
git clone https://github.com/Olegkg2018/ua-energy-arbitrage.git
cd ua-energy-arbitrage

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите библиотеки
pip install -r requirements.txt
```

#### 2. Запуск веб-интерфейса
```bash
python3 app.py
```
Приложение запустится в режиме реального времени и будет доступно в браузере по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000).

---

### Вариант 2: Запуск в Docker

Вы можете запустить приложение в изолированном контейнере без установки Python на локальную машину.

#### 1. Сборка Docker-образа
```bash
docker build -t ua-energy-arbitrage .
```

#### 2. Запуск контейнера
```bash
docker run -d -p 5002:5000 --name ua-energy-arbitrage ua-energy-arbitrage
```
После запуска проект будет доступен по адресу: [http://127.0.0.1:5002](http://127.0.0.1:5002).

---

### Вариант 3: Запуск через Docker Compose (Рекомендуемый)

Для быстрого управления контейнерами используйте Docker Compose.

*   **Запустить во фоновом режиме**:
    ```bash
    docker compose up -d
    ```
*   **Остановить и удалить контейнер**:
    ```bash
    docker compose down
    ```

## 💡 Как работать с программой (Инструкция диспетчера)

### Шаг 1. Задание параметров оборудования и тарифов
1. В левой части экрана введите технические характеристики вашей BESS: **Емкость (кВт-ч)** (например, 4000) и **Мощность (кВт)** (например, 1000).
2. Установите **Вхідну ємність (Початковий SoC, %)** (например, 20% или 100%, если батарея заряжена с предыдущих суток).
3. Перейдите во вкладку «Довідник тарифів та АКБ» и в один клик примените сетевой тариф нужного вам Облэнерго Украины. Тариф автоматически рассчитает стоимость передачи, распределения и диспетчеризации.

### Шаг 2. Расчет автоматического оптимума
1. Выберите дату планирования на верхней панели и модель ИИ (рекомендуется **XGBoost**).
2. Нажмите кнопку **«Розрахувати Розклад»**.
3. Система за секунду выполнит прогноз цен РДН, проверит погоду и построит математически оптимальный график BESS с использованием солвера PuLP (CBC).
4. Ознакомьтесь с финансовым результатом в карточке «Чистий прибуток». Он учитывает амортизацию батареи (деградацию ячеек).

### Шаг 3. Ручная корректировка графика
Если вы хотите переопределить часы работы батареи вручную:
*   **Перетаскивание столбиков по высоте**: Наведите мышь на бирюзовый (заряд) или розовый (разряд) столбик на графике мощности BESS и перетащите его край вверх или вниз для изменения киловатт.
*   **Перемещение столбика по часам**: Зажмите клавишу **Shift** на клавиатуре, захватите столбик и потащите его горизонтально влево или вправо. Отпустите мышь над нужным часом. Блок мощности переместится на новое время без изменения высоты.
*   **Редактирование через таблицу**: Перейдите во вкладку **«Погодинний графік»**. Выберите режим часа из выпадающего списка и введите точное значение мощности в кВт.
*   *Обратите внимание*: Карточка прибыли подсветится оранжевым цветом и появится индикатор **«Ручне керування»**.

### Шаг 4. Автоматическая балансировка BMS
При ручном редактировании легко допустить переразряд батареи ниже минимума или оставить её в конце суток разряженной, что принесет убытки на следующие сутки.
*   Нажмите зеленую кнопку **«Авто-баланс BMS»** в почасовой таблице.
*   Система автоматически сгладит ваши пики, чтобы уровень заряда никогда не опускался ниже $10\%$ и не превышал $90\%$, а также скорректирует заряд или разряд так, чтобы в конце суток уровень энергии вернулся точно к значению **Вхідної ємності** (например, 20%).
*   При необходимости сброса всех ручных правок нажмите кнопку **«Скинути до оптимуму»**.

### Шаг 5. Экспорт результатов
После согласования графика нажмите кнопку **«Експорт в CSV»** для выгрузки почасового расписания и импорта его в промышленную систему автоматизации (EMS) накопителя.
